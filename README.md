# 🌎 Aether AI

## Do Espaço para a Sustentabilidade da Terra

### Sobre o Projeto

O **Aether AI** é uma plataforma web desenvolvida para demonstrar como tecnologias espaciais podem contribuir para a preservação ambiental e para a geração de valor econômico através dos créditos de carbono.

A solução integra conceitos de monitoramento ambiental, inteligência artificial, sustentabilidade e tecnologia espacial, permitindo que usuários visualizem riscos ambientais e estimem o potencial de captura de carbono em áreas preservadas.

Este projeto foi desenvolvido para o **Global Solutions FIAP**, alinhado ao tema de inovação, impacto social e utilização de dados provenientes da indústria espacial.

---

## 🎯 Objetivos

* Demonstrar a aplicação de dados de satélites em problemas reais.
* Monitorar riscos ambientais de forma simples e visual.
* Simular cálculos de créditos de carbono.
* Integrar Front-end, Back-end e Banco de Dados.
* Promover a conscientização ambiental através da tecnologia.

---

## 🚀 Funcionalidades

### Monitoramento Ambiental

* Visualização de regiões monitoradas.
* Identificação de riscos ambientais.
* Indicadores de queimadas.
* Indicadores de seca.
* Alertas simulados.

### Calculadora de Carbono

* Cadastro de propriedades rurais.
* Informar área preservada.
* Cálculo estimado de CO₂ capturado.
* Estimativa de créditos de carbono.

### Dashboard

* Interface amigável.
* Layout responsivo.
* Informações ambientais em tempo real (simuladas).

## 🌍 Como Funciona

### Fluxo da Solução

1. O usuário acessa a plataforma.
2. Escolhe entre monitoramento ambiental ou créditos de carbono.
3. Insere os dados da propriedade.
4. O sistema realiza os cálculos.
5. Os resultados são exibidos no dashboard.
6. As informações podem ser utilizadas para análise ambiental e tomada de decisão.

## 🛰 Relação com a Tecnologia Espacial

O projeto utiliza o conceito de obtenção de dados ambientais através de satélites de observação da Terra.

Esses dados permitem:

* Monitoramento climático
* Detecção de queimadas
* Avaliação de cobertura vegetal
* Análise de impactos ambientais

Na versão acadêmica do projeto, os dados são simulados para fins educacionais.
